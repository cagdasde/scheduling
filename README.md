# AI-Based Classroom Scheduling System

This project is an AI-powered classroom scheduling system developed using Genetic Algorithms.

## 🚀 Features
- Optimized course scheduling
- Classroom and time slot assignment
- Constraint-based optimization

## 🧠 Algorithm
Genetic Algorithm is used to generate optimal scheduling solutions by evaluating fitness scores based on constraints.

## 💻 Tech Stack
- Node.js (Backend)
- Vue.js (Frontend)
- MySQL (Database)

## 📌 Purpose
This project is part of a master's thesis focused on solving scheduling problems in educational institutions.
